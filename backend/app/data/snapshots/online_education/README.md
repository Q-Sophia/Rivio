# Online Education Snapshot

Scenario: online education real-time interaction and virtual classroom solutions.

Competitors:
- ClassIn
- Tencent Cloud real-time interaction / education solution
- BigBlueButton

Collect sources first, then extract atomic evidence.

Minimum target for v0.1:
- 8-12 source documents
- 24-32 evidence records

Preferred source priority:
1. Official product pages
2. Official feature or documentation pages
3. Official pricing pages
4. Official security, deployment, SDK, or API pages
5. Trusted third-party technical references only when official sources are missing

Collection dimensions:
- positioning: SaaS / PaaS / meeting platform / open-source classroom
- feature: whiteboard, breakout rooms, recording, polling, classroom tools
- pricing: public pricing or billing model
- ecosystem: SDK/API, LMS integration, cloud ecosystem, open-source ecosystem
- customer: target users and education segments
- risk: deployment complexity, vendor lock-in, operations, compliance
