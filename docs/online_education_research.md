# 在线教育实时互动解决方案调研

调研对象：
- ClassIn
- 腾讯云实时互动 / TRTC 教育方案
- BigBlueButton

你只需要按“页面 + 原文摘录”的方式填资料。后续我会帮你整理成：
- `sources.json`
- `evidence.json`

## 采集目标

每个竞品先收集：
- 2-4 个官方或可信页面
- 每个页面 2-5 条原文摘录

优先使用：
1. 官方产品页
2. 官方功能页
3. 官方文档/API/SDK 页面
4. 官方定价/计费页面
5. 官方 GitHub 仓库或可信技术文档

## 建议关注维度

你不需要严格分类，但摘录时可以优先找这些内容：

- 产品定位：SaaS / PaaS / 视频会议 / 开源虚拟教室
- 功能基线：白板、分组讨论、录制、课堂互动、实时音视频等
- 技术接入：SDK、API、LMS 集成、自部署、云服务依赖等
- 商业模式：价格、套餐、按用户/按分钟/按并发计费等
- 目标客户：学校、培训机构、企业培训、开发者、教育 SaaS 厂商等
- 风险限制：部署复杂度、供应商锁定、运维、安全合规等

## 填写说明

- 一个页面就是后续的一条 `SourceDocument`。
- 一个页面里的每条原文摘录会被拆成一条或多条 `SourceEvidence`。
- “可能维度”和“备注/我的理解”都是可选项，不知道可以留空。
- 原文摘录尽量短一些，最好一条摘录只包含 1-2 个事实。
