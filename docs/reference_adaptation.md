## Adapted Mechanisms

| Reference mechanism | Local adaptation |
| --- | --- |
| `BaseAgent` role wrapper | `backend/app/agents/base.py` defines a lightweight `BaseAgent` with `name`, `role`, `input_artifacts`, `output_artifacts`, and `execute(context)`. |
| Agent runtime lifecycle | `backend/app/agents/runtime.py` creates and saves `AgentRun`, records timestamps/duration/errors, and writes `DAGNode.output_refs`. |
| Tool registry / handler dispatch | `backend/app/tools/registry.py` registers local tools and records `ToolCall` automatically on every `call()`. |
| DAG node state flow | `backend/app/workflow/dag.py` keeps the fixed sequential DAG but delegates node execution to `AgentRuntime`. |
| Trace artifacts | Existing `TraceRecorder` remains the trace persistence boundary for `dag_nodes`, `agent_runs`, and `tool_calls`. |
| Harness evaluation | `backend/harness/metrics.py` and `backend/harness/run_eval.py` turn artifact and trace checks into metrics and write `eval_summary.json`. |
| Task/report/trace API shape | Only used as structural reference for future API work. No FastAPI code was migrated in Milestone 6. |

## Direct Code Migration

No full reference directories or full source files were copied.

The Milestone 6 implementation uses small-scale structural adaptation:

- Class and responsibility boundaries were adapted from the reference projects.
- Function bodies were rewritten for the current deterministic, evidence-first pipeline.
- LLM, web search, crawler, FastAPI, frontend, team inbox, background task, worktree isolation, long-term memory, and full MCP server code were not migrated.

## Current Local Scope

Milestone 6 remains a local snapshot workflow:

```text
SourceDocument
-> SourceEvidence
-> ProductCard
-> AnalysisClaim
-> CitationCheck
-> CompetitiveReport
-> ReviewFeedback
```

The runtime/registry/evaluation work wraps this chain without replacing it.
